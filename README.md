# CodeSquad Portfolio

This portfolio website was created as part of my CodeSquad submission. It represents my progress in learning and applying HTML and CSS to build a responsive personal portfolio website.

## About the Project

The website was developed primarily using:

- HTML
- CSS
- Git and GitHub
- GitHub Pages

While building the portfolio, I applied concepts and techniques I learned through freeCodeCamp training materials, particularly when creating layouts, box elements, spacing, styling, and page structure.

## Learning Resources and Acknowledgments

I used the tutorial by Spruce Emmanuel as an important reference while building this portfolio:

[How to Build a Simple Portfolio Website with HTML and CSS](https://www.freecodecamp.org/news/build-a-simple-portfolio-website-with-html-and-css/)

The tutorial helped me understand how to structure and organize a portfolio website using HTML and CSS. I adapted the ideas and examples to create a portfolio that reflects my own background, skills, and interests.

I also used other online resources while troubleshooting and improving the website. Stack Overflow was particularly useful for understanding specific HTML and CSS issues and learning from solutions shared by the developer community.

## What I Learned

Through this project, I practiced and strengthened my understanding of:

- Semantic HTML structure
